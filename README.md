# 🧟 Zombie Shooot

A browser-based first-person zombie survival shooter built with **Three.js**.

## Play

Open `index.html` in a modern browser, or enable GitHub Pages for the repository.

### Controls

- **W A S D** — move
- **Shift** — sprint
- **Mouse** — look / aim
- **Left click** — shoot
- **R** — reload
- **Space** — jump

## Features

- First-person 3D rendering with Three.js
- Pointer Lock mouse aiming
- Raycaster hitscan shooting
- Procedural zombie enemies
- Wave-based spawning and increasing difficulty
- HP, score and ammunition HUD
- Reloading, damage feedback and game-over flow
- Dynamic fog, lighting, shadows and procedural environment
- No build step: Three.js is loaded from jsDelivr

## Tech

- HTML5 / CSS3
- JavaScript ES Modules
- Three.js 0.180.0
